# WEB⚡BITS — Creative Technology Studio

> An immersive, high-performance creative technology portfolio and digital platform engineered by **Infas.mk** ([NIT Raipur](https://nitrr.ac.in)).

---

## ⚡ Overview

**WEB⚡BITS** is a creative technology and spatial web development studio focused on building high-performance, interactive, and cinematic digital products. Combining engineering rigor with real-time 3D graphics, WEB⚡BITS bridges the gap between tactile visual design and ultra-fast web performance.

---

## 🚀 Key Highlights & Architectural Features

- **Custom 3D Monogram Centerpiece**: Procedural metallic WEB⚡BITS W⚡ sculpture with real-time mouse tracking, concentric orbital gyro rings, and dynamic wireframe/solid toggle built with React Three Fiber and Three.js.
- **Pinned Horizontal Gallery**: Signature case-study showcase with vertical-to-horizontal scroll pinning and 3D perspective tilt cards.
- **Scroll-Aware Dynamics**: Auto-hiding navbar, kinetic velocity-reactive marquee ticker, and scroll-linked editorial word highlights.
- **Technology Arsenal Wall**: Interactive skill cards with proficiency indicators, architecture filters, and benchmark telemetry.
- **Tactile Sound Synthesizer**: Zero-asset audio engine running entirely via Web Audio API for subtle cybernetic UI clicks and warps.
- **Ultra-Fast Performance**: Custom Vite chunk splitting (`vendor-three`, `vendor-motion`, core entry) and zero-delay boot sequence.
- **Responsive & Accessible**: Seamless responsive mobile fallback, custom cursor with contextual labels, and reduced-motion consideration.

---

## 🛠 Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **3D & Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Animation & Transitions**: Framer Motion
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Audio Engine**: Web Audio API Synth

## 📦 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/infasmk/portfolio-.git
cd portfolio-
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
